# Surface Pen Mapper 사용 가이드

[English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

Surface Pen Mapper는 **두 개의 사이드 버튼이 있는 Windows 펜을 4개의 동작으로 활용**할 수 있게 해주는 초경량 프로그램입니다.

현재 **Surface Pro 12 + Lenovo Active Pen 3(MPP)** 조합에서 실제 동작을 확인했습니다.

## 1. 설치

1. GitHub **Releases**에서 최신 `surface-pen-map-arm64.zip`을 받습니다.
2. 원하는 폴더에 압축을 풉니다.
3. `surface-pen-map.exe`를 실행합니다.

설치 프로그램이나 별도 Wacom 드라이버는 필요하지 않습니다.

Windows SmartScreen이 처음 실행을 확인할 수 있습니다. GitHub Releases에서 받은 파일인지 확인한 뒤 실행하세요.

## 2. 버튼 설정

펜의 두 사이드 버튼은 각각 두 가지 방식으로 사용할 수 있습니다.

| 제스처 | 사용 방법 |
| --- | --- |
| 상단 버튼 클릭 | 화면을 건드리지 않고 버튼을 눌렀다 놓기 |
| 상단 버튼 + 화면 탭 | 상단 버튼을 누른 채 펜촉으로 화면 탭 |
| 하단 버튼 클릭 | 화면을 건드리지 않고 버튼을 눌렀다 놓기 |
| 하단 버튼 + 화면 탭 | 하단 버튼을 누른 채 펜촉으로 화면 탭 |

각 제스처마다 원하는 동작을 따로 지정할 수 있습니다.

- 뒤로 / 앞으로
- 왼쪽 / 오른쪽 / 가운데 클릭
- 키 또는 단축키
- 추가 동작 없음

## 3. 키 또는 단축키 지정

동작에서 **키 / 단축키**를 선택한 뒤 오른쪽 입력칸을 클릭하고 원하는 키를 누릅니다.

예:

- `Enter`
- `Esc`
- `Tab`
- `Space`
- `Delete`
- 방향키
- `F1` ~ `F24`
- `Ctrl+Z`
- `Ctrl+Shift+T`
- `Alt+Left`
- `Win+D`

`Ctrl+Alt+Delete`는 Windows 보안 시퀀스라 사용할 수 없습니다.

## 4. 추천 설정 예시

마우스 없이 펜으로 Windows를 조작한다면 다음 구성이 편합니다.

| 제스처 | 추천 |
| --- | --- |
| 상단 버튼 클릭 | Enter |
| 상단 버튼 + 화면 탭 | 추가 동작 없음 |
| 하단 버튼 클릭 | 뒤로 |
| 하단 버튼 + 화면 탭 | Esc |

원하는 앱에 맞춰 자유롭게 바꾸면 됩니다.

## 5. 적용 및 자동 실행

설정을 바꾼 뒤 **적용**을 누르면 바로 활성화됩니다.

**Windows 로그인 시 자동으로 실행**을 체크하면 다음 로그인부터 백그라운드에서 자동 시작합니다.

설정창의 X를 눌러도 프로그램은 종료되지 않고 시스템 트레이로 숨겨집니다. 트레이 아이콘을 클릭하면 설정창을 다시 열 수 있습니다.

## 알아둘 점

Windows의 원래 펜 동작 자체를 제거하는 프로그램은 아닙니다.

특히 **상단 버튼을 누른 채 화면을 탭하는 동작은 Windows 기본 우클릭도 함께 발생할 수 있습니다.** 필기 앱에서는 하단 버튼의 기본 지우개 동작이 남을 수도 있습니다.

문제가 있을 때만 [문제 해결 가이드](TROUBLESHOOTING.md)를 확인하세요.
