# Surface Pen Mapper — 使い方

[한국어](README.ko.md) · [English](README.en.md) · [简体中文](README.zh-CN.md)

Surface Pen Mapper は、**2つのサイドボタンを4つのジェスチャーとして設定できる**軽量な Windows ユーティリティです。

現在、**Surface Pro 12 + Lenovo Active Pen 3 (MPP)** で実機確認しています。

## 1. インストール

1. GitHub の **Releases** から最新の `surface-pen-map-arm64.zip` をダウンロードします。
2. 好きなフォルダーに展開します。
3. `surface-pen-map.exe` を実行します。

インストーラーや別途 Wacom タブレットドライバーは不要です。

初回起動時に Windows SmartScreen が確認を表示する場合があります。GitHub Releases から取得したファイルであることを確認してから実行してください。

## 2. ペンのボタンを設定する

2つのサイドボタンは、それぞれ2種類の操作に分けられます。

| ジェスチャー | 操作方法 |
| --- | --- |
| 上ボタンをクリック | 画面に触れず、押して離す |
| 上ボタン + 画面タップ | 上ボタンを押したままペン先で画面をタップ |
| 下ボタンをクリック | 画面に触れず、押して離す |
| 下ボタン + 画面タップ | 下ボタンを押したままペン先で画面をタップ |

各ジェスチャーには個別に次の操作を割り当てられます。

- 戻る / 進む
- 左 / 右 / 中クリック
- キーまたはショートカット
- 追加操作なし

## 3. キー / ショートカットを割り当てる

動作で **Key / shortcut** を選び、右側の入力欄をクリックしてから割り当てたいキーを押します。

例:

- `Enter`
- `Esc`
- `Tab`
- `Space`
- `Delete`
- 矢印キー
- `F1` ～ `F24`
- `Ctrl+Z`
- `Ctrl+Shift+T`
- `Alt+Left`
- `Win+D`

`Ctrl+Alt+Delete` は Windows のセキュアアテンションシーケンスのため割り当てできません。

## 4. おすすめ設定例

マウスを使わずペン中心で Windows を操作する場合の例です。

| ジェスチャー | おすすめ |
| --- | --- |
| 上ボタンをクリック | Enter |
| 上ボタン + 画面タップ | 追加操作なし |
| 下ボタンをクリック | 戻る |
| 下ボタン + 画面タップ | Esc |

用途に合わせて自由に変更してください。

## 5. 適用と自動起動

設定を変更したら **Apply** を押します。変更はすぐに有効になります。

**Start mapper when I sign in to Windows** を有効にすると、次回ログイン時から自動でバックグラウンド起動します。

設定ウィンドウを閉じてもアプリは終了せず、システムトレイに隠れます。トレイアイコンをクリックすると設定画面を再度開けます。

## 注意

このアプリは Windows 標準のペン動作を置き換えるのではなく、追加の操作を送信します。

そのため、**上ボタンを押したまま画面をタップすると Windows 標準の右クリックも同時に発生する場合があります。** 手書きアプリでは下ボタンの標準消しゴム動作が残る場合もあります。

問題がある場合のみ [Troubleshooting](TROUBLESHOOTING.md) を確認してください。
